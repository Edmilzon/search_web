roducción
La Web Semántica surge como una evolución tecnológica que permite a las computadoras procesar e interpretar la información de forma inteligente a través de estructuras de datos interconectadas. Los pilares fundamentales son las ontologías y los lenguajes de representación del conocimiento, tales como RDF (Resource Description Framework) y OWL (Web Ontology Language)
En este informe se desarrollará un Buscador Semántico aplicando dichas tecnologías sobre un área de conocimiento específica, la cual ha sido seleccionada y descrita detalladamente para el modelado de la ontología. El desarrollo del proyecto abarcará el diseño del motor de búsqueda y la conexión directa con DBpedia, permitiendo la descarga de datos abiertos y el poblado de la base de conocimiento local con información estructurada. Asimismo, el sistema integrará el soporte para multilingualidad para ser usado en distintos idiomas.
A lo largo de este documento se explicará acerca de la ontología de mascotas domésticas, las herramientas utilizadas y el prototipo realizado.
II. Objetivos
Objetivo General
Desarrollar un motor de búsqueda semántica basado en una ontología de mascotas domésticas (perros y gatos) mediante el uso de los lenguajes OWL y RDF, integrando el poblado de datos desde DBpedia y el soporte para multilingualidad, con el fin de obtener resultados precisos.
Objetivos Específicos
Diseñar y modelar la ontología de mascotas domésticas (perros y gatos) 
Poblar la base de conocimiento local mediante la extracción e integración con DBpedia.
Implementar el motor de búsqueda semántica
Incorporar multilingualidad (español e inglés) para la consulta de la información. 
Validar el funcionamiento del prototipo 
III. Marco teórico 

3.1 Web Semántica
La Web Semántica surge como una evolución de la Web tradicional con el objetivo de transformar la información disponible en Internet en conocimiento comprendido por personas y computadoras. Web Semántica propone una red de conocimiento basada en relaciones entre datos.
La Web Semántica busca solucionar este problema mediante tecnologías capaces de representar información de forma estructurada utilizando ontologías y modelos semánticos.
3.2 RDF (Resource Description Framework)
RDF es un modelo de datos utilizado para representar información distribuida y reutilizable mediante grafos, lo que facilita el intercambio de datos entre sistemas de forma independiente y escalable. La información en RDF se estructura rigurosamente a través de enunciados llamados tripletas compuestos por:
Sujeto
Predicado
Objeto
Ejemplo:  Firulais → perteneceA → Perro
Entre las principales características de RDF se encuentran:
Independencia
Escalabilidad
Intercambio de información
Representación mediante grafos
Uso de recursos y propiedades semánticas
3.3 OWL (Web Ontology Language)
OWL es un lenguaje de representación de conocimiento basado en lógica descriptiva que permite construir ontologías dentro de la Web Semántica.  
Mediante OWL es posible representar conocimiento de un dominio específico utilizando axiomas, clases, individuos y propiedades. Además, permite realizar razonamiento automático e inferencia sobre los datos almacenados.
Entre las herramientas más utilizadas para trabajar con OWL se encuentra Protégé, editor de ontologías compatible con OWL 2 y diversos razonadores como Pellet, FaCT++ y Hermit.
3.4 Ontologías
Una ontología es una especificación formal y explícita de los términos en un dominio y de las relaciones entre ellos 
Las ontologías permiten:
Representar conocimiento de forma estructurada.
Integrar información de diferentes recursos.
Compartir vocabularios comunes dentro de un dominio.
Una ontología OWL se compone principalmente de:
Clases.- Representan conjuntos de individuos con características comunes.
Ejemplo:
Mascota
 ├── Perro
 └── Gato
Individuos.- Son los objetos específicos del dominio representado.
Ejemplo:
Firulais : Perro
 Michi : Gato
Propiedades.- Permiten relacionar individuos entre sí o asignar características.
Ejemplo:   
Firulais tieneDueño Juan
Las ontologías permiten que las computadoras entiendan, compartan, reutilicen y separen el conocimiento humano de manera organizada para que otros programas puedan usar esos datos.
3.5 Buscadores Semánticos
Los buscadores semánticos son sistemas capaces de interpretar el significado de las consultas realizadas por los usuarios utilizando relaciones conceptuales y ontologías.
A diferencia de los motores de búsqueda tradicionales, el buscador semántico utiliza modelos RDF y OWL para comprender el contexto de la información y obtener resultados.
Dentro del presente proyecto, el buscador semántico permitirá realizar consultas relacionadas con mascotas domésticas (gato y perro).

4.2 ¿Qué es una Mascota?
Una mascota es un animal doméstico que convive con las personas principalmente con fines de compañía y cuidado. Las mascotas requieren atención relacionada con alimentación, salud, higiene y bienestar.
En este proyecto se trabajará principalmente con: Perros y Gatos. Debido a que representan las mascotas domésticas más comunes y permiten modelar relaciones semánticas variadas dentro de la ontología.
Las mascotas podrán poseer información relacionada con:
Nombre
Edad
Peso
Raza
Tipo de alimento
Dueño
Cuidados específicos
Accesorios

VI. Conclusiones
A la conclusión del presente proyecto de investigación y desarrollo, se exponen los siguientes resultados y consideraciones finales:
Modelado Exitoso del Dominio: Se logró diseñar, validar y estructurar una ontología robusta sobre mascotas domésticas utilizando la herramienta Protégé, logrando integrar con éxito un total de 110 mascotas, 30 razas y 60 dueños dentro del archivo base en formato RDF/XML. La definición explícita de propiedades de objeto (como consume, tieneDueño y tieneRaza) y de datos permitió capturar la semántica real y las interconexiones lógicas del dominio estudiado.
Efectividad del Motor de Búsqueda Semántica: El prototipo desarrollado demostró que la combinación de Python, la librería rdflib y el lenguaje de consultas SPARQL es sumamente eficiente para interrogar grafos de conocimiento locales. A diferencia de las bases de datos relacionales tradicionales que requieren un mapeo rígido de tablas, las consultas SPARQL nativas permitieron navegar por las relaciones jerárquicas e inferidas de la ontología de forma flexible y ágil.
Interfaz Accesible e Interactiva: La implementación de Streamlit y pandas en la capa de presentación cumplió con creces el objetivo de abstraer la complejidad técnica de la Web Semántica para el usuario final. Se obtuvo una interfaz limpia e intuitiva, capaz de transformar datos estructurados en tripletas complejas en tablas interactivas legibles y dinámicas para el control de los usuarios (propietarios, veterinarias o refugios).
Validación de la Web Semántica: El proyecto valida el potencial de las tecnologías de la Web Semántica en la resolución de problemas de organización del conocimiento. Al estructurar la base de datos bajo los estándares del W3C (OWL/RDF), el sistema queda completamente preparado para futuras expansiones, tales como la interconexión con fuentes de datos abiertas enlazadas (Linked Data) como DBpedia o la adición de módulos multilingües avanzados mediante etiquetas de metadatos (rdfs:label).
