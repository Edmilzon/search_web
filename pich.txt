Actúa como tu base de datos.El Cerebro (Backend): Python + la librería rdflib. Esta librería es la encargada de abrir tu archivo OWL, entenderlo y ejecutar las consultas SPARQL que tú ya escribiste.La Cara (Frontend): Python + la librería streamlit. Esta librería crea la página web, dibuja el "buscador tipo Google", recoge lo que escribe el usuario y muestra los resultados en una tabla bonita.¿Cómo es el flujo de trabajo?El usuario entra a tu página web $\rightarrow$ Escribe "Perro" en el buscador de Streamlit $\rightarrow$ Python toma esa palabra y se la pasa a rdflib $\rightarrow$ rdflib mete "Perro" en tu consulta SPARQL y busca en el archivo OWL $\rightarrow$ rdflib devuelve los resultados a Streamlit $\rightarrow$ Streamlit pinta una tabla en pantalla.2. He adaptado tu propia consulta SPARQL para que funcione con la barra de búsqueda:Pythonimport streamlit as st
from rdflib import Graph
import pandas as pd

# 1. Configurar la página (El "Bootstrap" de Streamlit)
st.set_page_config(page_title="Buscador de Mascotas", page_icon="🐾", layout="centered")

st.title("🐾 Buscador Semántico de Mascotas")
st.write("Escribe el nombre de una especie (ej. Perro, Gato) para ver las razas y mascotas registradas en nuestra Ontología.")

# 2. Cargar la Ontología (Esto lo hace rdflib)
# Usamos cache para que no vuelva a leer el archivo cada vez que buscas algo
@st.cache_resource
def cargar_ontologia():
    g = Graph()
    g.parse("mascotas.owl", format="xml") # Asegúrate que el nombre coincida
    return g

grafo = cargar_ontologia()

# 3. La interfaz: El buscador tipo "Google"
busqueda_usuario = st.text_input("🔍 Buscar por Especie (ej. Perro):")

# 4. Cuando el usuario escriba algo y presione Enter o haga clic en buscar:
if busqueda_usuario:
    
    # Preparamos tu consulta SPARQL, inyectando lo que el usuario escribió
    query_sparql = f"""
    PREFIX : <http://www.semanticweb.org/mascotas#>
    PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

    SELECT ?nombresMascota ?nombresRaza
    WHERE {{
      ?mascota :tieneRaza ?raza .
      ?raza :perteneceAEspecie ?especie .

      ?mascota :nombre ?nombresMascota .
      ?raza :nombre ?nombresRaza .
      
      # Aquí metemos la palabra que el usuario escribió en el buscador web
      ?especie :nombre "{busqueda_usuario}"^^xsd:string .
    }}
    """
    
    # 5. Ejecutar la consulta
    resultados = grafo.query(query_sparql)
    
    # 6. Transformar los resultados para mostrarlos bonito (Tu "migración a JSON/Tablas")
    datos_para_tabla = []
    for fila in resultados:
        datos_para_tabla.append({
            "Nombre de la Mascota": str(fila.nombresMascota),
            "Raza": str(fila.nombresRaza)
        })
        
    # 7. Mostrar resultados en la pantalla web
    if len(datos_para_tabla) > 0:
        st.success(f"¡Encontramos {len(datos_para_tabla)} resultados para '{busqueda_usuario}'!")
        
        # Streamlit + Pandas hacen magia aquí: dibujan una tabla estilo Bootstrap
        df = pd.DataFrame(datos_para_tabla)
        st.dataframe(df, use_container_width=True)
    else:
        st.warning("No se encontraron mascotas para esa especie. ¡Intenta con otra!")
